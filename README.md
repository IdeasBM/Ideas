## Cómo continuar
Leer este README, META, ROADMAP y la card activa antes de proponer trabajo.
Consultar fuentes actuales para hechos de mercado. Separar hechos, hipótesis y decisiones.
Una card termina cuando existe su entregable y se cumplen sus criterios de cierre.
Cada sesión debe producir algo visible; un descarte fundamentado también cuenta.
No iniciar la construcción de varios productos a la vez.
