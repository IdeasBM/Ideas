## Proyecto activo — Task Fixer
Decisión del responsable: 2026-10-03. Todo el foco pasa a Task Fixer. Lana y las otras opciones quedan en el archivo de antecedentes.

[Entrar a la carpeta Task Fixer](projects/task-fixer/README.md) · [Proyecto rector](projects/task-fixer/PROYECTO.md) · [Card activa #13](https://github.com/IdeasBM/Ideas/issues/13).

Task Fixer es una agencia de diseño de procesos, selección de herramientas, creación, reparación y mantenimiento de automatizaciones. Mercados elegidos: negocios latinos en Estados Unidos y México, comenzando por Veracruz. Sectores prioritarios de investigación: restaurantes y contratistas/construcción.
